## Анимации (уровень Apple / Linear / Stripe)

- **Hero:** видео плавно уменьшается и уходит на параллаксе, буквы заголовка «выезжают» из-под маски со стаггером.
- **Reveal:** clip-mask появления построчно (не банальный fade), стаггер через CSS-переменные.
- **Spaces:** горизонтальный скролл-пин, привязанный к прогрессу скролла (rAF).
- **Rigs:** 3D-наклон карты за курсором, построчное раскрытие спеков, янтарная кромка.
- **Cinema:** счётчик 130″/6, аудио-волна Dolby Atmos.
- **Микро:** магнитные кнопки, кастомный курсор, «дышащее» свечение CTA, живой статус часов.
- Всё уважает `prefers-reduced-motion`.

## Две версии сайта

| | Локальная | Артефакт |
|---|---|---|
| Файлы | `index.html` + `style.css` + `script.js` | `respawn-artifact.html` (один файл, 874 КБ) |
| Медиа | настоящее видео, 43 МБ | стоп-кадры из тех же клипов + Ken Burns |
| Шрифты | Google Fonts по сети | woff2 вшиты в base64 |
| Кириллица в заголовках | падает на системный шрифт | Manrope 200 (у Space Grotesk нет кириллицы) |
| Звук | кнопка mute в Hero | нет (нечего включать) |
| Кодировка | UTF-8 | чистый ASCII (`&#x…;` / `\u…`) — обёртку `<head>` мы не контролируем |

**Локальная версия — источник правды.** Правки вносим в неё, артефакт пересобираем:

```bash
python3 build-artifact.py
```

Сборщик инлайнит CSS/JS, меняет `<video>` на `<img>` с data-URI из `assets-src/`, вырезает кнопку звука и падает с ошибкой, если разметка разъехалась (число видео, наличие патчируемых блоков в `script.js`). Кадры лежат в `assets-src/`, шрифты — в `assets-src/fonts.css`.

Панели «The Spaces» и Hero — широкие, а клипы вертикальные, поэтому у каждого кадра свой `object-position` (см. `ARTIFACT_CSS` в сборщике): без этого центральный кроп срезает главное — вывеску VIP, экран кинозала.

### Как открыть
```bash
cd "web respan" && python3 -m http.server 8823
```
затем `http://localhost:8823` (нужен интернет для шрифтов Google Fonts). Либо открыть `index.html` напрямую.

### Что вне рамок прототипа
Реальное бронирование/оплата (кнопки ведут в Instagram), CMS, ключ Google Maps (стилизованная карта-плейсхолдер).

## v3.1 — красно-чёрная палитра, искры, детализированный объект, видео-акценты

**Палитра.** Единственный акцент сменился с янтарного на красный (`--amber:#E23B3B`,
`--ember:#FF5A2A` — его горячий конец, для искр и свечения). Зелёный (`--live:#46C46B`)
появляется ровно в одном месте — живой статус «Открыто сейчас»: это осознанный
семантический цвет («работаем»), а не второй акцент.

**Геометрия гарнитуры и геймпада уточнена по референсным фото**, которые прислал
пользователь: полная дуга оголовья (двойной обод с перемычками), шарнирные хомуты в
месте крепления чашек, овальные (не круглые) амбушюры с накладным диском-логотипом,
провисающая штанга микрофона с поролоновым наконечником. У геймпада — тачпад между
стиками (как у DualSense), крестовина, диамант из четырёх кнопок (одна — акцентная,
как нажатая), плечевые курки короткими отростками по верхним углам, кнопка home.
Цвета рёбер читаются из CSS-переменных (`--amber`, `--ember`, `--fg`) через
`getComputedStyle`, а не зашиты числом — палитра меняется в одном месте.

**Искры.** Второй canvas под объектом (`.hero__embers`) — частицы поднимаются от
основания объекта и по всему кадру, гаснут по синусоиде, у каждой мягкий ореол
(двойная отрисовка circle) — читается как тлеющие угли, не как салют.

**Видео вернулось точечно.** Короткие клипы (3–5 сек, экспортированы
`AVAssetExportPresetLowQuality`/`MediumQuality` через `assets-src/clip.swift`,
70–480 КБ) как акценты движения:
- `.creed__ambient` — атмосферный фон секции-манифеста на 16% непрозрачности;
- `.plate__clip` — плашка «Смотреть» показывает настоящий кинозал в углу карточки.

Комнаты по-прежнему держат единственную полноценную фотографию/видео на клуб —
сетка залов; новые клипы — акценты, не замена сетки.

### Известное ограничение среды разработки
В этой сессии панель браузера периодически помечает вкладку как фоновую
(`document.hidden === true`), из-за чего Chrome троттлит `requestAnimationFrame`,
`IntersectionObserver` и декодирование видео — скриншоты и живые кадры не отражают
реальную скорость. Проверка в таких случаях идёт через DOM: `getComputedStyle`,
`getBoundingClientRect`, ручной `await video.play()`, textContent после ожидания
троттлинг-таймеров. Сама логика (наблюдатели, атрибуты, обработчики) не зависит от
этого и работает как обычно в реальном браузере пользователя.
