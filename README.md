## Что где лежит

| Путь | Что это |
|---|---|
| `src/respawn.template.html` | **Актуальная версия сайта (v4).** Вся разметка, CSS и JS одним файлом с токенами `{{CLIP:…}}` под ассеты |
| `build-v4.py` | Собирает `dist/respawn-v4.html` — то, что публикуется, — и `dist/preview.html` для локальной проверки |
| `tools/clipkit.swift` | Кодировщик видеопетель на AVFoundation: обрезка, поворот, cover-кроп, свой битрейт |
| `assets-src/clips2/` | Петли для хиро, плашек зон и кинозала, нарезанные clipkit из исходных съёмок |
| `docs/index.html` | **То, что раздаётся в интернет.** GitHub Pages и Vercel берут страницу отсюда. Файл собирается, руками не правится |
| `vercel.json` | Говорит Vercel раздавать `docs/`, иначе он подхватит что-нибудь другое из корня |
| `v2/` | Предыдущая версия сайта |
| `archive/` | Первая версия и её сборщик. Лежит только ради истории, никуда не публикуется |
| `build-v2.py` | Собирает страницу из `v2/` |
| `assets-src/` | Кадры, вытащенные из видео, и шрифты, инлайненные в base64 |
| `CONCEPT.md` | Концепция, арт-дирекшн, карта видео, отличия версий |
| `*.mp4` | Исходные съёмки клуба — из них взяты все кадры |
| `photo_*.jpeg` | Скриншоты прайс-листа из Instagram — первоисточник всех цен |

`components/`, `lib/`, `demo/` — обрывки React/shadcn из ранних проб, к сайту отношения не имеют.

## Запуск

Локально, с настоящим видео:

```bash
python3 -m http.server 8823
```

затем `http://localhost:8823/v2/`.

## Пересборка страницы для публикации

```bash
python3 build-v4.py
```

Инлайнит шрифты, видео и картинки в один самодостаточный HTML. Разметку экранирует
числовыми HTML-ссылками, а тело `<script>` — escape-последовательностями `\uXXXX`:
строки оттуда попадают в `textContent`, где `&#x20AC;` напечатался бы буквально.
Рядом кладёт `dist/preview.html` — ту же страницу в обёртке `<!doctype html>`, потому
что голый фрагмент с диска открывается в quirks mode и ведёт себя не так, как в проде.

Перекодировать видео (нужен только при замене исходников):

```bash
swiftc -O tools/clipkit.swift -o /tmp/clipkit
/tmp/clipkit "исходник.mp4" assets-src/clips2/zone-vip.mp4 480 854 0.2 3.0 500
# два плана в одной петле: старты и длительности через запятую
/tmp/clipkit "исходник.mp4" assets-src/clips2/cinema.mp4 960 600 13.4,7.5 2.2,1.6 900
```

### Предыдущая версия

```bash
python3 build-v2.py
```

Скрипт инлайнит CSS и JS, меняет каждый `<video data-still="имя">` на `<img>` с кадром
из `assets-src/имя.jpg` в виде data-URI, дописывает `@font-face` и отдаёт результат
чистым ASCII — обёртку `<head>` на площадке публикации мы не контролируем, поэтому на
объявление кодировки полагаться нельзя. Сборка падает с внятной ошибкой, если разметка
разъехалась: пропал `data-still`, нет кадра, скрипт перестал быть IIFE.

## Ограничения площадки публикации

Страница публикуется под жёсткой политикой безопасности: внешние шрифты, скрипты,
iframe и медиа не загружаются. Отсюда решения:

- шрифты (Cormorant Garamond, Inter, JetBrains Mono) вшиты в base64 — только бесплатные;
- видео заменено кадрами из тех же клипов;
- живой эмбед ленты Instagram и iframe Google Карт невозможны — вместо них ссылки;
  на обычном хостинге и то и другое включается, точки вставки помечены в разметке.

## Данные

Цены, тарифы Пик/Вне пика и спецификации сборок сверены со скриншотами прайс-листа
в корне репозитория. Менять их — только вместе с ними.
